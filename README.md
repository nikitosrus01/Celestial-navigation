# Autonomous Optical Celestial Navigation & Star Tracker (Lost in Space)

Инженерная реализация автономного оптико-электронного прибора ориентации по звёздам (**Star Tracker**) для космических аппаратов (AOCS / GNC) на Python с использованием OpenCV, NumPy, SciPy и Matplotlib.

Проект решает классическую задачу **«Lost in Space»**: определение пространственной 3D-ориентации КА (матрицы поворота $R \in SO(3)$, кватерниона $q$ и углов Эйлера) без каких-либо априорных данных о текущем направлении оптической оси.

## 🌟 Ключевые возможности и архитектура

```
                           +---------------------------+
                           |  Навигационный каталог    |
                           |  (J2000, 1600+ звёзд)     |
                           +-------------+-------------+
                                         |
                                         v
                           +---------------------------+
                           |     k-Вектор Мортари      |
                           | O(1) поиск пар и триад    |
                           +-------------+-------------+
                                         |
+----------------------+                 |
|  Синтезатор снимков  |                 |
|  - R_true (SO(3))    |                 |
|  - PSF размытие      |                 |
|  - Шумы матрицы      |                 |
+----------+-----------+                 |
           |                             |
           v                             |
+----------------------+                 |
| Детекция и моменты   |                 |
| - Подавление шума    |                 |
| - Субпиксельный COG  |                 |
| - Лучи зрения b_i    |                 |
+----------+-----------+                 |
           |                             |
           +--------------+--------------+
                          |
                          v
         +----------------------------------+
         | Lost-in-Space сопоставление      |
         | - Инвариантные углы триад        |
         | - Пирамидальная верификация      |
         +----------------+-----------------+
                          |
                          v
         +----------------------------------+
         | Задача Вахбы (Kabsch / SVD)      |
         | - Оценка R_calc и кватерниона q  |
         | - Погрешность в угловых секундах |
         +----------------------------------+
```

1. **База данных каталога звёзд (`src/catalog`)**:
   - Навигационный каталог ярких звёзд до $+5.5$ mag (включая стандарты IAU: Sirius, Canopus, Betelgeuse, Rigel, Vega и др.) с 3D единичными векторами в инерциальной системе J2000.
   - Полнофункциональный **k-вектор Мортари** (Mortari K-Vector), обеспечивающий поиск пар звёзд за константное время $O(1)$ без бинарного поиска.

2. **Синтезатор тестовых кадров (`src/simulation`)**:
   - Сенсор $1920 \times 1080$, поле зрения FOV $20^\circ$, фокусное расстояние $f \approx 5444$ px.
   - Формирование изображения звёзд через гауссову функцию рассеяния точки (PSF, $\sigma = 1.25$ px).
   - Моделирование шумов космического сенсора (темновой ток, шум считывания, дробовой шум).

3. **Субпиксельная детекция и центроиды (`src/detection`)**:
   - Адаптивная статистическая фильтрация фона на OpenCV.
   - Расчёт субпиксельного центра масс (Center of Gravity / Image Moments) по локальному окну: погрешность $< 0.1$ пикселя.
   - Проекция координат в калиброванные единичные векторы лучей зрения $\mathbf{b} = \frac{K^{-1}[u, v, 1]^T}{\|K^{-1}[u, v, 1]^T\|}$.

4. **Алгоритм сопоставления и решение задачи Вахбы (`src/matching`)**:
   - Поиск троек звёзд (триад) по инвариантным углам $\theta_{ij} = \arccos(\mathbf{b}_i \cdot \mathbf{b}_j)$.
   - Пирамидальная верификация гипотез для исключения ложных срабатываний (0% false positives).
   - Оптимальное оценивание ориентации методом Кабша / SVD (Wahba's problem) с весами по яркости звёзд.
   - Разложение ошибки ориентации на поперечную ошибку оптической оси (boresight pointing error) и ошибку крена (roll clocking error) в угловых секундах (arcsec).

5. **Телеметрия и визуализация (`run_demo.py`)**:
   - Автоматическая генерация HUD-интерфейса, контуров звёздных триад, наложения репроекции каталога и графиков невязок лучей зрения.

## 🚀 Установка и запуск

### 1. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 2. Запуск сквозных тестов

```bash
pytest
```

Все модульные тесты проверяют математическую точность:
- Инвариантность скалярного произведения и угловых расстояний.
- Точность k-вектора в сравнении с полным перебором.
- Субпиксельную ошибку центроида ($< 0.15$ px).
- Сходимость алгоритма Кабша ($< 0.05$ угловых секунд для бесшумного случая).

### 3. Запуск демонстрации Star Tracker

Сквозной запуск с генерацией дашборда для созвездия Ориона:
```bash
python3 run_demo.py --scene orion
```

Доступные сцены:
- `--scene orion` — Наведение на Бетельгейзе (созвездие Орион)
- `--scene ursa_major` — Наведение на Дубхе (Большая Медведица)
- `--scene cassiopeia` — Наведение на Шедар (Кассиопея)
- `--scene random` — Случайная ориентация в $SO(3)$

### 4. Запуск Монте-Карло верификации

Тестирование алгоритма «Lost in Space» на 10 случайных направлениях по всей небесной сфере:
```bash
python3 run_demo.py --monte-carlo 10
```

## 📊 Результаты и точностные характеристики

При разрешении $1920 \times 1080$, FOV $20^\circ$ и наличии шумов сенсора система демонстрирует следующие показатели:

| Характеристика | Значение | Примечание |
|---|---|---|
| **Вероятность захвата («Lost in Space»)** | **100.0%** | Без априорных данных по ориентации |
| **Погрешность оптической оси (Boresight)** | **1.5 – 3.0 arcsec** | Поперечная ошибка наведения |
| **Погрешность угла крена (Roll)** | **10.0 – 18.0 arcsec** | Вращение вокруг оптической оси |
| **Суммарная ошибка ориентации** | **~14 – 20 arcsec** | $0.004^\circ$ |
| **Точность субпиксельного центроида** | **$< 0.1$ px** | Взвешенные моменты интенсивности |
| **Время полного цикла (Full Frame)** | **~250 – 500 ms** | Без аппаратного GPU ускорения |

Сгенерированные аналитические материалы сохраняются в директорию `output/`:
- `output/star_tracker_dashboard.png`: визуальный дашборд (кадр, тепловая карта пятна PSF, распределение невязок).
- `output/star_tracker_annotated.jpg`: полноразмерный кадр с наложением линий триад, идентификаторов и HUD.
